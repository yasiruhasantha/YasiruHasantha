## 📌 Projects

| Project | What it does |
| --- | --- |
| **[KeyMind](https://github.com/yasiruhasantha/keymind)** | AI-powered focus assistant. Uses Google Gemini to judge whether your current window or browser tab is relevant to your task, and closes it if it isn't. Windows, macOS and Linux (X11, Hyprland, sway, GNOME Wayland). |
| **[Distraction Slayer](https://github.com/yasiruhasantha/distraction-slayer)** | The predecessor to KeyMind — a Python script that detects distracting apps/tabs and shuts them down, with optional Arduino buzzer for a physical nudge. |
| **[Coffee Shop](https://github.com/yasiruhasantha/Coffee-shop)** | Early front-end project — a responsive coffee shop landing page built with plain HTML/CSS. |
